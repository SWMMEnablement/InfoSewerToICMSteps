InfoSewer to ICM Conversion Toolkit

This app is an interactive guide and toolkit for engineers converting InfoSewer projects into InfoWorks ICM format. It walks through the recommended single-script InfoSewer Import Tool, and it keeps the older nine-step ODIC process on hand as a fallback for cases where the newer tool cannot be used.

Alongside the conversion walkthrough, the toolkit includes four browser-based helpers: a Node ID Compliance Checker, a CSV Field Validator, a SQL Script Builder, and a Pre-Conversion Readiness Checklist, so users can validate their data before committing to an import.
